# agentstock

License-clean stock images and video for AI agents — semantic search, browse, and pay-per-use purchase via x402, exposed as a remote MCP server.

- **Website:** <https://agentstock.dev>
- **MCP endpoint:** `https://agentstock.dev/mcp` (streamable HTTP)

## Connect

Point any MCP client at the remote endpoint:

```
https://agentstock.dev/mcp
```

## About this repo

This repository holds listing metadata only — **no server source code**. The MCP server runs as a hosted remote service; the manifest in [`server.json`](server.json) describes it for registry and directory ingestion.
